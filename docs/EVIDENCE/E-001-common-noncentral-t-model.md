# E-001 — The whole family reduces to one `(ν, δ)` pair

| | |
|---|---|

| **Method** | Structural black-box probing + published-output comparison |
| **Target** | G\*Power 3.1.9.x, test family `t tests` |
| **Probe id** | `P-01` |

## Claim

Every one of the six statistical tests in the `t tests` family contributes
exactly two numbers — degrees of freedom `ν` and noncentrality `δ` — and
nothing else. All five analysis types are then pure functions of
`(ν, δ, α, k)`.

## Why this is not simply "what the manual says"

The manual documents a *noncentral t* model per test, but it documents each
test in its own section with its own notation, and never states the stronger
structural claim that the tests share a single evaluation path. The structural
claim is what is actually load-bearing for an implementation: it is the reason
a single power routine suffices, and it is what makes the three cross-checks in
E-003, E-004 and E-007 valid derivations rather than coincidences.

## Probe `P-01` — observable surface of the structural claim

The claim predicts that the GUI's **Output Parameters** panel exposes `δ`,
critical `t`, `ν` and power for *every* test in the family, with no additional
test-specific output field, and that two tests that happen to produce the same
`(ν, δ)` produce byte-identical output panels.

### Click path

`Test family = t tests` → iterate `Statistical test` over all six entries →
`Type of power analysis = Post hoc` → fill the required inputs → **Calculate**
→ read the Output Parameters panel.

### Prediction

1. The output panel always contains exactly: `Noncentrality parameter δ`,
   `Critical t`, `Df`, sample-size field(s), `Power (1-β err prob)`.
2. No test adds a further distributional output (no variance-ratio, no
   approximation flag).
3. Supplying inputs that coincide in `(ν, δ)` across two different menu entries
   yields identical `δ`, `Critical t`, `Df` and `Power`.

## Independent corroboration

The canonical published G\*Power output for the family —

```
Means: Difference between two independent means (two groups)
a priori, two tails, d = 0.5, α = 0.05, power = 0.95, allocation ratio = 1
  →  δ = 3.6228442, Critical t = 1.9714347, Df = 208,
     n₁ = n₂ = 105, N = 210, Actual power = 0.9501287
```

— is reproduced by this engine to all seven printed decimals, from the
`(ν, δ)` model alone:

```console
$ gpower solve --test ttest-indep-means --solve n \
      --alpha 0.05 --power 0.95 --effect-size 0.5 --tails 2
...
  Noncentrality parameter delta  = 3.6228442
  Critical t                     = 1.9714347
  Df                             = 208
  Sample size group 1            = 105
  Sample size group 2            = 105
  Total sample size              = 210
  Actual power                   = 0.9501287
```

Reproducing four independent printed quantities simultaneously from a
two-parameter model is strong evidence that the model is the right one; a
different `δ` convention would match at most one of them.
